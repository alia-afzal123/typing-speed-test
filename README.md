# ⌨️ Typing Speed Test

A modern, interactive typing speed test application built with **React.js** that helps you measure and improve your typing skills.



## ✨ Features

| Feature | Description |
|---------|-------------|
| ⏱️ **Time Options** | Choose from 30s, 60s, or 120s tests |
| 📚 **Difficulty Levels** | Easy, Medium, and Hard paragraphs |
| 🎯 **Real-time Feedback** | Correct (green) / Incorrect (red) highlighting |
| 📊 **Detailed Results** | Gross WPM, Net Speed, Accuracy, Mistakes |
| 🎨 **Modern UI** | Glassmorphism design with dark theme |
| 📱 **Responsive** | Works on desktop, tablet, and mobile |

---


## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| React.js | Frontend framework |
| Vite | Build tool |

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm (comes with Node.js)

### Installation

```bash
# Clone the repository
git clone https://github.com/alia-afzal123/typing-speed-test.git

# Navigate to project folder
cd typing-speed-test

# Install dependencies
npm install

# Start development server
npm run dev
